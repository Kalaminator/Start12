## Menu styles (Config UI: "Start menu style")
- Windows 7 style | Modern Style | Windows 10 Style | Windows 11 Style (10<->11 change needs reboot). "Windows 10 style with improvements"; "Windows 10 inspired look".
- Win10 layout: left rail (user, docs, settings, power etc.) + app list (recent/most used on top, then All apps A-Z, "Use Windows 10 style all programs list rather than Win7 style", "Open all apps list as menu", "Default to all programs list on open", folders at bottom, Universal apps in own folder, Desktop/Fences folders) + tile area. Win10 style folders option; "Show more tiles on start"; "Use fullscreen menu" (fullscreen keeping taskbar visible).
- Tiles: "Show icons as tiles", "...split into N columns" (3,4,5,6,7,8 Columns), tile texture/image background, custom grid tile bg, faded tile bg, tooltip caption on hover, hide labels, close button on active tiles, custom static tile images (Experimental), "Load standard app icon instead of a tile", "Pick custom tile image...", X/Y offset (medium/small-wide spacing), rounding: square (Win10) / medium rounded. Tile groups stored in GroupContents key with GroupText/GroupBackground/GroupColour, user-nameable groups; exact pixel sizes are code-constants (not in strings): use Win10 standard 50px small / 100px medium / 200x100 wide / 200px large with 4px gap.
- Power: "Clicking the power button should" -> (PowerButtonMode enum: shut down / sleep / restart / sign out etc.); menu entries: Shut down, Restart, Sleep, Hibernate, Sign out, Lock, Switch user, Disconnect; RDP-only extras hidden by default (RDPShowShutdown). Option to show icon on shutdown button.
- Places list ("Right") items: see IDs above; SmallRight = small items.

## Skin/theme format (Default.spak)
- `file`: data, 694459 B, entropy 7.9998, first 4 bytes 00000000 then random -> encrypted/compressed proprietary (7z cannot open). Do NOT try to reuse; author own skin format. Textures live as plain PNG in MenuTextures/ TabTextures/ TaskbarTextures/ StartButtons/ (Default.png, DefaultMedium.png, DefaultLarge.png, Arsenic Orb, Biohazard...). Theme files: `*.Start8Theme` (ExtractS8Theme converts old Start8 themes -> Start10 skin).
- defs.ini = editor schema listing skin sections (ordered groups): 1 Top Left: LeftMenu, .Expanded, .Line, .Selection(2 frames), .SelectionLeftSplit, .SelectionRightSplit, .TreeMode | 2 Top Right: RightMenu, .Expanded, .Line, .Selection, .ExpandedSelection | 3 SearchMode, SearchMode.Bottom | 4 MorePrograms.Background/.Arrow/.Mouseover | 5 BottomMenu.Left/.LeftExpanded/.Right/.RightExpanded, SearchField | 6 ShutdownButton, .Arrow, .Expanded, .ExpandedArrow | 7 UserPicture, SearchField.Icon1 magnifier/Icon2 X/Icon3 hover X/Icon4 pressed X | 8 Texture1..5.
- Per-section keys (ThemeHelp.txt): Image, UserColourLayer (1 replace with user colour; 2,3,4 alt), TextureMode(1-5), TextureAlignmode(0/1/2), FrameCount (vertical frames), RenderAsGroup, PartWidth/PartHeight, PaintMargins/LayerMargins/ContentMargins (l,t,r,b, comma+SPACE), RenderDefaultArrow, AlphaValue, Tile (bitmask 16 middle,1 left,2 right,4 top,8 bottom), AlphaMode, TreatAsGlyph, TextColour, MouseoverColour, PressedColour, GroupColour (R, G, B). Editor-schema keys: Description, Description2, Required, Shift, Filter, ShowText/ShowMargins/ShowWidth, NoImage.
- defs2.ini: Transparency sections Left/Right/Top/Bottom each Default=0 (transparent region px).

## Hotkeys / input
- Win key opens: Start11 menu / Windows menu / (desktop vs fullscreen app separately). Right Win = alt menu; Ctrl+Win, Shift+Win, hold Win 0.5s simulate right Win. Ctrl+click Start button opens Windows menu. Right-click start = Win+X menu (ShowWinX) else Start11 menu (Configure Start11, Run, Shutdown). Menu opens on monitor under mouse (option). Typing while open starts search; if Start11 search disabled keystrokes open Windows search. Hot corners (Start8-era): DisableCharms/TopLeft.

## Search
- "Use Start11 Search" (S11Search.exe/64: separate search host) vs Cortana/Windows search (UseCortanaSearch) vs classic; Windows 7 style small-icon results. Options: search file contents (slower), files outside standard libraries, desktop+Fences shortcuts, Edge open tabs, search-the-internet button (Google/Bing), filtering icons, Everything integration (if installed replaces non-app file search), NoIndexer (don't use Windows Search), NoSearchControlPanel. History in RecentSearches/Searches keys; "Clear search history". Taskbar search box hide/show.
- Clone approach: KRunner/baloo + .desktop app match.

## Executables
- Start11.exe/Start10.exe: launcher stub -> loads Start10_32/64/A64.dll (the shell hook / menu engine, also has ms-settings: URI list for settings search, AppxManifest reading for tiles).
- Start11_64/_A64, Start11_2_64: x64/ARM64 menu hosts ("Start11"). Start11Srv: service. Start11Config: MFC settings UI (10MB, pages: Start menu, Start button, Taskbar, Search, Menu appearance/theme, Power, Desktop, Backup/Restore, Licence). Start10tweak: Advanced taskbar tweaks / licence UI (Start8 trial strings), explorer restart. Start10ThemeEdit: .spak theme editor. ExtractS8Theme: converts `*.Start8Theme`. PinMenu/PinLaunch: pin-menu launcher (pin items to Start11). S11Search(64): search host. SdDisplay: .NET display/DPI helper (Stardock.ApplicationServices). Launch/Launch2: .NET launcher stubs. DeElevate(64)+DeElevator(64).dll: run app unelevated. SasUpgrade: licence upgrade. mrmsupport.dll: MS resource lookup for UWP app names/icons. zip.exe: backup compression.
- Languages: lang/*.lng (24).
