## 1. Menu styles and substyles

Question: "Which style of Start Menu would you prefer?" (`MenuMode`, substyles `Win7StyleSub`, `ModernStyleSub`; "Substyle :"). "This menu style has no substyles. Change options for it using the link below."
Master toggle: "Enable Start11 Menu"; "Show the Windows start menu" / "Show the Windows menu when I Ctrl-click the Start button".

Styles (description strings):
- "Windows 7 style" - "The classic Windows 7 menu." Substyles: "Windows 7 style with icons", "Compact Windows 7 style", "Grid Windows 7 style", "Grid Windows 7 style with icons", "Compact Grid Windows 7 style". Two-pane: pinned+MFU list on left, places list + shutdown on right, search box bottom, "All Programs" tree.
- "Modern style" - "An updated Windows 7 style." Substyles: "Modern style with icons", "Compact Modern style", "Grid Modern style", "Grid Modern style with icons", "Compact Grid Modern style". Also "Modern theme", "Modern theme without icon", "Windows 10 inspired look", "Without user icon".
- "Windows 10 style" - "Windows 10 style with improvements." (tiles; see section 2).
- "Windows 11 style" - "Windows 11 style with improvements." / "An updated Windows 11 style."
- Further style names present in strings (v2 extras): "Windows App style", "Windows Pro style", "Windows Launcher style" (the last = tabbed/grouped launcher, see 2b), "Custom image" (menu), "Abstract One" (texture).
- Warning: "Changing between Windows 10 style and Windows 11 style requires a reboot!" [WIN-ONLY]
- Menu size: "What size should it be?" / "Menu Size" / "Menu size mode": "Small", "Tall", "Wide", "Large", "Full screen" (`Size`, `Win11Width`, `Win11Height`, `Win12Width/Height`, `Win10WidthC`, `WiderMetroBlocks`, `WideSmallMode`).
- "What mode should it start in?" / "Default to the applications view" (`DefaultApps`), "Default to the all programs list on menu open" (`DefaultToAllProgs`), "Start menu should open showing all programs list" (`OpenAllProgs`/`OpenAllProgs11`).
- "What should show on the menu?"; "Additional options"; "Configure" / "Configure menu" ("Adjust colour, transparency, icon size, and many other settings.").
- "Use fullscreen menu" (`UseFullScreenMenu`); "The menu should be fullscreen but leaving the taskbar visible" (`SemiFull`); `OffsetFullScreen10`.

What each shows:
- Win7/Modern: pinned apps, "Show my most used applications after my pinned shortcuts" (MFU, `UseSimpleMFU`, `ItemCount` "Show at least N shortcuts"), recent apps, "Quick access shortcuts" places list on right (Computer, Control Panel, Documents, Music, Pictures, Run..., etc.), power button, search box, "All Programs" tree (or "Use Windows 10 style all programs list rather than Windows 7 style" `NewProgsListMode`).
- Win10: left column (user/power/settings), app list, tile area.
- Win11: pinned grid + "Recommended"-like recents + all-apps.
